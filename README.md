# MeetingDesk

**Живая расшифровка встреч, аудиозапись и конспекты — в одном приложении для Mac и Windows.**

MeetingDesk записывает ваш микрофон и звук компьютера, показывает разговор текстом прямо во время встречи и помогает вернуться к тому, что обсуждали раньше. После встречи можно получить краткий конспект, решения, задачи и открытые вопросы, а затем сохранить всё в Obsidian.

Приложение работает на вашем компьютере: приглашать бота на встречу не нужно. Распознавание выполняет Deepgram, конспекты создаются через подключение ChatGPT или OpenAI API.

> Текущая версия — **0.4.0, тестовая сборка**. Бот для встреч и интеграция с Notion пока не реализованы.

## Что умеет

- **Писать встречу:** микрофон и звук компьютера сохраняются в локальный WAV. Видео экрана не записывается.
- **Показывать текст в прямом эфире:** можно прокрутить к началу, найти фразу и вернуться к текущему разговору.
- **Разделять реплики:** ваш микрофон — «Вы», голоса собеседников — «Участник 1», «Участник 2» и далее. Имена не определяются.
- **Помогать по ходу встречи:** личные заметки с автосохранением, закладки и исправление отдельных реплик.
- **Собирать итоги:** обзор, решения, задачи и открытые вопросы со ссылками на исходные реплики.
- **Работать поверх других окон:** небольшое окно с транскриптом и заметками, настройка прозрачности.
- **Сохранять в Obsidian:** Markdown и копия аудиозаписи в вашем хранилище. Можно экспортировать в обычную папку.
- **Обновляться из приложения:** проверка новой версии, загрузка и установка с перезапуском.

## Что нужно для работы

| Что | Для чего | Обязательно? |
| --- | --- | --- |
| API-ключ Deepgram и доступный баланс/кредит | Живая расшифровка и разделение голосов | Да, для распознавания |
| Интернет | Работа облачных сервисов | Да, для живого текста и конспекта |
| Подключение ChatGPT **или** отдельный ключ OpenAI API | Итоговый конспект и задачи | По желанию |
| Разрешения ОС на микрофон и захват звука | Запись выбранных источников | Да |
| Папка хранилища Obsidian | Экспорт встреч | По желанию |
| Наушники | Уменьшают дублирование звука в микрофоне | Рекомендуются |

Ключ Deepgram добавляется в настройках приложения. Подключение ChatGPT не заменяет Deepgram. Для конспектов через ChatGPT доступ зависит от аккаунта и разрешений, используются лимиты плана; OpenAI API — отдельный вариант подключения.

Для экспорта в Obsidian аккаунт Obsidian не требуется.

## Первый запуск за несколько шагов

1. На Mac распакуйте архив и перенесите MeetingDesk в **Программы**. На Windows запустите установщик.
2. Откройте настройки, добавьте [API-ключ Deepgram](https://console.deepgram.com/) и сохраните.
3. Для конспектов выберите **Подписка ChatGPT → Continue with ChatGPT**, завершите вход в браузере и выберите доступную модель. Либо подключите OpenAI API своим ключом.
4. При необходимости выберите папку хранилища Obsidian.
5. Создайте встречу, выберите микрофон и звук компьютера, пройдите проверку **Доступы** и начните запись.
6. После встречи остановите запись, проверьте текст и откройте **Конспект**. Используйте **Экспорт → В Obsidian** для сохранения.

Для знакомства без ключей есть **Посмотреть пример**. Это вымышленные данные; демонстрация ничего не отправляет в облако.

## Настроить обновления

В версии 0.4 откройте **Настройки → Обновления**, укажите:

```text
puzyrcult/meetingdesk-releases
```

Нажмите **Сохранить источник**, затем **Проверить обновления**. При появлении новой версии будут доступны загрузка и установка. Во время записи или обработки встречи установка недоступна.

Для перехода с 0.1–0.3 на 0.4 потребуется один раз установить новую версию вручную. Не удаляйте папку данных: подключения и встречи хранятся отдельно от приложения.

## Данные и стоимость

Аудио и транскрипты сохраняются на вашем компьютере. Для распознавания аудио отправляется в Deepgram; для конспекта текст передаётся в OpenAI. У провайдеров действуют собственные условия обработки и хранения.

API-ключи и сеансы входа защищаются средствами ОС. У аудио и транскриптов нет отдельного шифрования приложения. Кнопка **Открыть папку данных** находится в настройках.

Распознавание оплачивается через ваш аккаунт Deepgram. Оценка расхода в MeetingDesk приблизительная и не является балансом провайдера. Реальные списания проверяйте в [кабинете Deepgram](https://console.deepgram.com/).

Этот репозиторий содержит документацию, установщики и файл обновления. Пользовательских ключей, сеансов входа и записей здесь нет. Автоматические архивы GitHub **Source code** содержат файлы этого репозитория, а не исходный код приложения.

## Текущие ограничения

- Нет бота для Zoom/Meet/Teams, Notion, календаря и синхронизации устройств.
- Захватывается весь системный звук, включая уведомления; фильтрации одного приложения нет.
- Несколько людей у одного микрофона в режиме «Только микрофон» будут обозначены как «Вы».
- Разделение голосов может ошибаться, особенно при одновременной речи.
- При обрыве сети аудио сохраняется локально; пропуски живого текста нужно восстановить после встречи.
- Работа при сне компьютера и смене аудиоустройств не гарантируется.
- Windows-сборка подготовлена, но полный сценарий на Windows ещё требует ручной проверки. Живой звонок с настоящими источниками также нужно проверить на вашей системе.
